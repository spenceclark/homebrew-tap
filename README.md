# homebrew-tap

Homebrew tap for [vessel](https://github.com/spenceclark/Vessel).

```bash
brew tap spenceclark/tap
brew install vessel
```

`Formula/vessel.rb` is bumped automatically by vessel's release workflow on
every tagged release — this repo isn't edited by hand. The version checked in
right now (`0.0.0`) is a placeholder until the next release runs the bump.

Supports macOS (Apple Silicon) and Linux (x64 and arm64). Intel Macs aren't
published — build from source instead.
